# BUG-001 — ระบบจำลองอนุญาตให้สร้าง PR เมื่อ Quantity = 0

> **Hypothetical Sample Defect:** ไม่ใช่ Bug ที่พบจากระบบ SAP จริง

| Field | Detail |
|---|---|
| Requirement | REQ-003 |
| Related Test Case | TC-003 |
| Module | PR Creation |
| Severity (สมมติ) | Medium — PR ผิด Business Rule |
| Priority (สมมติ) | High |
| Status | Example Only / Not Reported |
| Environment | Mock scenario; no SAP instance |

## Preconditions
Role `PR_CREATOR`, Material `MAT-1001`, วันที่อ้างอิง 2026-11-08

## Steps to Reproduce (จำลอง)
1. เปิด Create Purchase Requisition
2. ระบุ Material = `MAT-1001`
3. ระบุ Quantity = `0` และ Required Date = `2026-11-09`
4. กด Save

## Expected Result
ระบบปฏิเสธ Quantity = 0 และไม่สร้าง PR ตาม REQ-003

## Actual Result (สมมติ)
ระบบแสดงบันทึกสำเร็จและสร้าง PR ID แม้ Quantity = 0

## Impact
ข้อมูล PR ไม่เป็นไปตามกฎธุรกิจ อาจกระทบขั้นตอนถัดไป

## Suggested Retest
ทดสอบ Quantity = -1, 0, 1 และ 5 พร้อมตรวจสอบว่าไม่สร้าง PR สำหรับข้อมูลผิด
