# BUG-002 — ผู้ใช้ VIEWER สามารถสร้าง PR ได้ในระบบจำลอง

> **Hypothetical Sample Defect:** ไม่ใช่ Bug ที่พบจากระบบ SAP จริง

| Field | Detail |
|---|---|
| Requirement | REQ-006 |
| Related Test Case | TC-009 |
| Module | PR Creation / Authorization |
| Severity (สมมติ) | High — Unauthorized Data Creation |
| Priority (สมมติ) | High |
| Status | Example Only / Not Reported |
| Environment | Mock scenario; no SAP instance |

## Preconditions
บัญชีทดสอบ Role `VIEWER` ไม่มีสิทธิ์สร้าง PR ตาม Requirement จำลอง

## Steps to Reproduce (จำลอง)
1. เข้าสู่ระบบด้วย `VIEWER`
2. พยายามเปิดหน้าสร้าง PR หรือส่งคำขอบันทึก
3. ระบุ Material = `MAT-1001`, Quantity = `5`, Required Date = `2026-11-09`
4. กด Save

## Expected Result
ระบบปฏิเสธทั้งที่ UI และ Server; ไม่มี PR ID ใหม่

## Actual Result (สมมติ)
ระบบบันทึก PR และสร้าง PR ID ให้บัญชี VIEWER

## Impact
ผู้ไม่มีสิทธิ์สร้างข้อมูลได้ ขัดกับกฎควบคุมการเข้าถึง

## Suggested Retest
ตรวจสอบ UI และ Server-side Authorization; ทดสอบ Role `PR_CREATOR` ว่ายังสร้าง PR ได้

**Evidence:** ไม่มี Screenshot/Log จริง เพราะไม่ได้ Execute
